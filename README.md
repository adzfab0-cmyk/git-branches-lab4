# Практическая работа №4. Работа с ветками в Git

Программа для работы с двумерным массивом (Python, NumPy).
Вариант 3: функции 3, 5, 12, 19, 31.

## Запуск

    pip install -r requirements.txt
    python main.py

## Ветки (GitFlow)

- `main` - стабильный код (первый и финальный коммиты);
- `develop` - ветка разработки;
- `feature/*` - по одной ветке на каждую задачу (пункт меню, функция).
